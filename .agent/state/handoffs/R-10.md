## 3. What Failed
- Default HTTP socket timeout in `OllamaConfig` was 30 seconds, causing `TimeoutError` when calling small local models for 3KB prompts.
- Small models (e.g. `llama3.2:1b`) often returned plain text descriptions or non-unified C++ snippet diffs instead of standard unified diffs, resulting in `apply_patch` returning `rejected_reason: diff does not apply`.
- Model output wrapped JSON payloads inside markdown fences (` ```json `), triggering `json.loads` decode errors before fence stripping was added.
- Nested workspace tree copy in `make_verify_diff` caused infinite directory recursion when the temp directory was inside `source_dir`.

## 4. What Was Changed
- **`verifieds/proposer/client.py`**:
  - Increased default timeout to 120s (`VERIFIEDS_OLLAMA_TIMEOUT`).
  - Added unwrapping for markdown code fences (` ```json ... ``` `).
  - Added JSON slice recovery for trailing prose or truncated response blocks.
- **`verifieds/schemas/models.py`**:
  - Added `mode="before"` coercions to `CandidateDraft` for `diff`, `expected_complexity_after`, `risks`, and `strategy`.
- **`verifieds/pipeline/engine.py`**:
  - Added `is_diff_safe` for path safety checks.
  - Added ignore patterns (`src_*`, `orig_*`, `cand_*`, `tmp*`, `.git`, `build`) during workspace `shutil.copytree`.
- **`verifieds/smoke.py`**:
  - Added `--verify` flag to trigger `verify_candidate` on model-proposed candidates.
- **`README.md`**:
  - Updated JSON-RPC client examples and documentation for `--verify` mode.
